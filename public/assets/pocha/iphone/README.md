# iPhone media

Captured 2026-10-20 from POCHA iOS on an isolated iPhone 17 Pro simulator using the existing POCHA_LAYOUT_PREVIEW and POCHA_LAYOUT_SCREEN flags. French and English use the real SwiftUI screens and offline preview fixtures; no user account or production backend is used. The community screenshot is the user-provided iPhone general-feed reference (English in both website locales). All images are resized to 600 px wide and encoded as WebP. The Android blog graphic comes from pocha-android/play-store-assets/feature-graphic-1024x500.png.
